# Jogo de Adivinhação em Python 

🎲 Este repositório contém a implementação de um jogo simples de adivinhação de números em Python. O projeto foi estruturado em múltiplos arquivos para demonstrar boas práticas de organização e uso de **Programação Orientada a Objetos (POO)**. 

## 🔹 Funcionalidades 
- Geração de um número secreto aleatório entre 1 e 100
- Validação de entradas do usuário (aceita apenas números inteiros)
- Mensagens de feedback: informa se o chute é maior ou menor que o número secreto
- Encapsulamento com atributos privados e uso de **getter/setter** para controle do número secreto
- Loop de jogo até que o usuário acerte o número

## 🔹 Estrutura do Projeto

📂 adivinhacao/
 ├── numeroEscolhido.py   # Classe que gerencia o número secreto
 └── main.py              # Arquivo principal que executa o jogo
